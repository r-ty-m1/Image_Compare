# 圖片前後對比嵌入器

> 把兩張圖片做成可左右拖曳的 Before／After 對比，並產生可直接貼進 Notion 的嵌入連結。

---

## 一、這個工具是什麼

**圖片前後對比嵌入器**是一個單一 HTML 檔（`index.html`）的網頁小工具，部署在 GitHub Pages 上即可使用，不需要後端、資料庫或安裝任何軟體。

它適合用來展示：

- AI 生圖的「原圖 → 生成結果」
- 修圖、調色、設計稿的前後差異
- 同一提示詞在不同模型或參數下的結果比較

---

## 二、能做什麼

### 對比檢視
- 拖曳圖片上的分隔線即可比較左右兩張圖，支援滑鼠與手機觸控。
- 左側為**圖片 A（Before）**、右側為**圖片 B（After）**，標籤文字可自訂，也可隱藏。
- 分隔線與把手採螢光綠發光設計（深色極簡風格）。

### 固定比例
- 提供 `3:4`、`4:5`、`9:16`、`1:1`、`4:3`、`16:9` 六種比例。
- **自動選擇比例**：選擇或載入圖片 A 後，會自動挑選最接近的比例（你仍可手動更改）。
- 嵌入後圖片會依比例**等比縮放、完整顯示、不裁切**；拉動 Notion 區塊的寬度或高度，比例都不會變。
- 嵌入頁背景為**透明**，圖片直接貼合 Notion 頁面。

### 提示詞
- 可為 A、B 各填一段提示詞與標題（預設 `Prompt(Before)`／`Prompt(After)`）。
- 嵌入後提示詞**預設摺疊**，點擊標題才展開，不佔版面。
- 可分別設定是否顯示。

### 圖片上傳
- 在編輯器中直接選擇圖片，上傳到**你自己的 GitHub 公開儲存庫**，上傳完成後自動填入 HTTPS 圖片網址。
- 也可以不上傳，直接貼上任何公開的 HTTPS 圖片網址。

### 嵌入連結
- 一鍵複製嵌入連結；複製後按鈕會自動還原，修改設定後連結會同步更新，可再次複製。
- 所有設定都編碼在連結中，不需要伺服器儲存。
- 可選擇是否在嵌入頁保留「編輯設定」按鈕（預設不顯示）。

### 記住設定
- 可勾選記住 GitHub 帳號／組織、儲存庫、分支與資料夾（僅存在目前瀏覽器）。
- **Token 永遠不會被儲存**。

## 三、使用平台與需求

| 項目 | 說明 |
|---|---|
| 嵌入平台 | **Notion**（`/embed` 區塊）。其他支援以網址嵌入網頁的平台理論上也可使用，但未逐一測試 |
| 託管平台 | **GitHub Pages**（放置 `index.html`） |
| 圖片儲存 | **GitHub 公開儲存庫**（或任何公開 HTTPS 圖片網址） |
| 瀏覽器 | 近年版本的 Chrome、Edge、Safari、Firefox（桌面與手機） |
| 圖片格式 | PNG、JPG、GIF、WebP、AVIF、BMP（**不支援 SVG**） |
| 圖片大小 | 單張 10 MB 以下 |
| 費用 | 免費（使用 GitHub 與 Notion 的免費功能即可） |

## 四、快速開始

整體流程只有三步：**部署 → 設定圖片 → 貼進 Notion**。

### 步驟 1：部署到 GitHub Pages

1. 建立（或選擇）一個 GitHub 儲存庫，將 `index.html` 上傳到根目錄。
2. 到儲存庫的 **Settings → Pages**，Source 選擇你的分支（通常是 `main`）與 `/ (root)`。
3. 等待部署完成，取得你的 Pages 網址（形如 `https://你的帳號.github.io/儲存庫名稱/`）。

> 📷 **【截圖位置】** GitHub Settings → Pages 的設定畫面
>
> <!-- 在此貼上截圖，例如：![GitHub Pages 設定](images/01-pages.png) -->

### 步驟 2：設定圖片與顯示方式

1. 開啟你的 Pages 網址，進入編輯器。
2. 在**圖片 A／圖片 B 網址**填入圖片網址；或使用下方「直接上傳圖片到 GitHub」（見下一節）。
3. 確認**顯示比例**（選圖後會自動挑選最接近的比例）。
4. 視需要修改標籤、提示詞與顯示選項，按「**套用預覽**」確認效果。

> 📷 **【截圖位置】** 編輯器整體畫面（圖片網址、比例、標籤、提示詞欄位）
>
> <!-- 在此貼上截圖，例如：![編輯器畫面](images/02-editor.png) -->

### 步驟 3：貼進 Notion

1. 按「**複製／取得嵌入連結**」。
2. 回到 Notion，在頁面輸入 `/embed` 並選擇 Embed 區塊。
3. 貼上連結，按「Embed link」。
4. 拖曳區塊邊緣調整大小；圖片會依設定比例等比縮放。

> 📷 **【截圖位置】** Notion 中輸入 `/embed` 並貼上連結的畫面
>

> 📷 **【截圖位置】** 嵌入完成後的最終效果（含展開提示詞）

## 五、直接從編輯器上傳圖片到 GitHub

### 1. 準備公開儲存庫
建立或選擇一個 **公開（Public）** 儲存庫專門存放圖片（Notion 必須能公開讀取圖片）。可以和部署工具的儲存庫相同，也可以分開。

### 2. 建立 Fine-grained Token
1. 前往 GitHub **Settings → Developer settings → Personal access tokens → Fine-grained tokens**，點「Generate new token」。
2. **Repository access** 選擇「Only select repositories」，只勾選存放圖片的那個儲存庫。
3. **Repository permissions** 將 **Contents** 設為 **Read and write**。
4. 建立後複製 Token（只會顯示一次）。

> 📷 **【截圖位置】** Token 建立畫面（Repository access 與 Contents 權限）
>
> <!-- 在此貼上截圖，例如：![建立 Token](images/05-token.png) -->

### 3. 在編輯器中上傳
1. 填入 **GitHub 帳號／組織**、**儲存庫名稱**；**分支**留空即使用儲存庫預設分支；**資料夾**可保留預設 `comparison-images`。
2. 貼上 **Token**。
3. 在「選擇圖片 A」「選擇圖片 B」各選一張圖片，按「**上傳選取的圖片**」。
4. 成功時會顯示綠色 ✔ 並自動填入圖片網址；失敗時會以紅色顯示原因。
5. 兩張圖片都就緒後，系統會同時產生嵌入連結。

> 📷 **【截圖位置】** GitHub 上傳區塊與上傳成功的狀態訊息
>
> <!-- 在此貼上截圖，例如：![上傳圖片](images/06-upload.png) -->

### 4. 記住設定（選用）
勾選「記住帳號、儲存庫、分支與資料夾」，下次開啟會自動填回。Token 不會被記住，需每次重新貼上。

## 六、設定項目一覽

| 項目 | 說明 | 預設值 |
|---|---|---|
| 圖片 A／B 網址 | 左側（Before）與右側（After）的 HTTPS 圖片網址 | 無 |
| 嵌入後圖片顯示比例 | 嵌入後固定的顯示比例 | 依圖片 A 自動選擇，否則 3:4 |
| 圖片 A／B 標籤 | 顯示在圖片左上、右上的文字 | `Before`／`After` |
| 提示詞 A／B 標題 | 摺疊區塊的標題 | `Prompt(Before)`／`Prompt(After)` |
| 提示詞 A／B | 展開後顯示的內文，留空則不顯示 | 空 |
| 顯示圖片標籤 | 是否顯示左右標籤 | 開 |
| 顯示提示詞 A／B | 是否在嵌入頁顯示提示詞 | 開 |
| 在嵌入頁保留編輯按鈕 | 嵌入頁是否顯示「編輯設定」 | 關 |

## 七、安全與隱私

- **Token**：只存在目前頁面的記憶體中，不會寫入嵌入連結、不會被「記住」；全部上傳成功後會自動清除，重新整理頁面也會消失。
- **最小權限**：Token 請限定單一儲存庫，且只開 Contents 的 Read and write。用完可到 GitHub 撤銷。
- **公開性**：公開儲存庫中的圖片任何人都能讀取，請勿上傳機密、私人或未授權的素材。
- **連結內容**：提示詞、標籤與圖片網址都編碼在嵌入連結中，任何拿到連結的人都能看到，請勿放入機密內容。
- 請避免在共用或不可信的電腦上輸入 Token。

## 八、限制與常見問題

**Q：上傳後沒有自動填入網址？**
看「上傳選取的圖片」下方的紅字訊息。常見原因：Token 未授權該儲存庫、Contents 權限不是 Read and write、帳號或儲存庫名稱拼錯、分支不存在（分支欄位留空可避免）。

**Q：預覽顯示「圖片無法載入」？**
請確認儲存庫是**公開**的、網址是 HTTPS、檔案不是 SVG。剛上傳的圖片偶爾需要幾秒同步，系統會自動重試數次。

**Q：嵌入後圖片兩側或上下有空白？**
圖片的長寬比與所選比例不同時，為了不裁切，會在框內保留空白。請選擇最接近圖片的比例（選圖時會自動挑選）。

**Q：嵌入頁的背景不是透明的？**
背景是否透明取決於 Notion 與瀏覽器的深淺色模式判斷。若遇到不透明色塊，請回報你的 Notion 與系統深淺色設定。

**Q：可以在 Notion 內直接編輯嗎？**
不行。一般 Notion 頁面無法把第三方網頁變成原生編輯區塊。流程是：在獨立編輯器設定 → 複製連結 → 貼進 Notion。若要修改，回到編輯器調整後重新複製連結即可（或勾選「在嵌入頁保留編輯按鈕」，從嵌入頁進入編輯）。

**Q：舊的嵌入連結會跟著更新嗎？**
不會。設定寫在連結裡，修改後需要重新產生並貼上新連結。
