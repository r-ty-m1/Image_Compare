直接上傳圖片到 GitHub

請使用公開儲存庫，Notion 才能讀取圖片。Token 只在目前頁面記憶體中使用，不會寫入嵌入網址，也不會被「記住」；全部上傳成功後會自動清除。請勿使用有不必要權限的 Token，也不要上傳公司機密或私人圖片。建議單張圖片低於 10 MB。

比例會固定在你選定的比例；Notion 調整嵌入區塊的寬或高時，圖片會等比縮放並完整顯示。提示詞與顯示選項會寫入產生的網址，請勿放入機密內容。

將網址部署到 GitHub Pages 後，在 Notion 輸入 /embed，貼上此網址即可。一般使用者開啟連結時只會看到比較內容，不會看到設定面板（除非勾選保留編輯按鈕）。
